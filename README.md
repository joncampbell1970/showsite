# Trades Website Features Demo

A production-ready Next.js showroom for a UK trades web agency. Every feature is interactive: quote estimator, booking, enquiry auto-responder, reviews, and SEO structure.

## Quick start

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

## Build for production

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. Import the project into Vercel.
3. Use the default Next.js settings.

## Demo data

Edit `src/data/demo.json` to update reviews, services, pricing, booking slots, and towns.

## Demo admin panel

Visit `/admin` to view in-memory submissions. Data resets when the server restarts.
